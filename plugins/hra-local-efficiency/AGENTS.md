# Contents

- `.codex-plugin/plugin.json` defines the plugin identity and Codex presentation metadata.
- `skills/hra-local-efficiency/` contains the operating skill, deterministic scripts, managed assets, and discovery metadata.

# Guidelines

- Keep the folder, manifest, marketplace entry, and skill identity aligned as `hra-local-efficiency`.
- Keep the manifest independently versioned and MIT licensed.
- Keep the plugin local-only and free of provider credentials, cloud execution, and cloud routing.
- Validate the manifest and complete skill before handoff. Keep implementation rules in the skill's closest guide.
