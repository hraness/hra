# Desktop runtime notices

HRA source builds use pinned third-party runtimes and assets:

- Bun `1.3.14` is embedded in the compiled gateway. `BUN-LICENSE.md` preserves its upstream inventory and LGPL relinking notice. `BUN-DEPENDENCY-LICENSES.json` and `.txt` preserve the complete checked license-document set for the 22 native source components and all 43 locked `lol-html` Cargo packages. `BUN-PROVENANCE.md` binds those notices to the deterministic complete Bun source bundle and the separate patched WebKit archive that accompany each native release.
- OpenAI Codex CLI `0.144.6` is distributed under Apache-2.0. The adjacent `CODEX-LICENSE.txt` and `CODEX-NOTICE.txt` preserve its primary license and notice. `CODEX-NATIVE-LICENSES.json` and `.txt` bind all five shipped npm payloads to the exact 969-package target Cargo graph, 16 source-built or fetched native components, and 561 unique license documents.
- The Codex platform runtime includes ripgrep `15.1.0`. `RIPGREP-COPYING.txt`, `RIPGREP-LICENSE-MIT.txt`, and `RIPGREP-UNLICENSE.txt` reproduce the exact files from its pinned tag. `PCRE2-LICENCE.md` conservatively preserves the terms for its statically linked PCRE2 `10.45` implementation, and `RIPGREP-PROVENANCE.md` binds both source commits and the shipped binary hash.
- Dugite `3.2.2` is distributed under MIT.
- Dugite Native Git `2.53.0`, release `v2.53.0-3`, is the checksum-pinned Git distribution. Git is GPL-2.0; `GIT-COPYING.txt` and `GIT-CORRESPONDING-SOURCE.txt` preserve the license and provenance, and the exact Git and Dugite Native source archives accompany each native release.
- Git LFS `3.7.1` is included in the pinned Git distribution. `GIT-LFS-LICENSE.md` preserves its exact MIT terms and embedded Go BSD notice; `GIT-LFS-PROVENANCE.md` binds its source commit, binary, version output, and license hash.
- Git Credential Manager `2.7.3` is included in the pinned Git distribution. `GIT-CREDENTIAL-MANAGER-LICENSE.txt`, `GIT-CREDENTIAL-MANAGER-NOTICE.txt`, and `GIT-CREDENTIAL-MANAGER-PROVENANCE.md` preserve its exact primary license, bundled notice, source commit, and binary hashes. `GCM-DEPENDENCY-LICENSES.json` and `.txt` preserve the exact license documents for all 22 external or runtime-pack identities that contribute its 214 shipped runtime assets.
- Native SDK supplies the macOS host framework used by the Zig application.
- Geist `1.800` and Geist Mono are distributed under the SIL Open Font License 1.1. Their source assets have adjacent OFL texts, and desktop builds preserve those licenses with the bundled frontend.
- `@hraness/ui` `0.3.1` supplies the pinned stylesheet compiled into the desktop renderer. `HRANESS-UI-LICENSE.txt` preserves its MIT terms, and `HRANESS-UI-PROVENANCE.md` binds the exact package, source commit, stylesheet, and license hashes. Its React components and Hugeicons dependencies are excluded from the desktop production JavaScript closure.
- `SHIPPED-JAVASCRIPT-LICENSES.json` and `.txt` contain the complete installed production dependency closure used to compile the frontend and Bun gateway. Packaging fails on missing package metadata, missing license documents, unexpected special files, hash drift, or an unreviewed package that omits its license text. `JAVASCRIPT-LICENSE-OVERRIDES.md` records the exact, version-pinned exceptions for defective published tarballs.

`runtime/runtime-versions.json` records the Codex package integrity, Dugite Native asset checksum, supported macOS floor, runtime binary hashes, source commits, and exact license hashes used by source builds. The same file is staged as `RUNTIME-VERSIONS.json` in the app.
